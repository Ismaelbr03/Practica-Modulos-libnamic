# Practica-modulos-libnamic

Módulo de backend para **Licium** que permite administrar checklists internas y sus ítems, con **CRUD completo**, acciones de **cierre/reapertura**, marcado de tareas, vistas de administración y control de permisos mediante **grupos y ACL**. Perfecto para aprender de manera práctica cómo crear y configurar módulos paso a paso.
